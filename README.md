#  Luxe Thread Co.

A modern, full-stack apparel catalog application featuring an interactive React frontend and a RESTful Flask backend.

---

##  Overview

**Luxe Thread Co.** allows users to browse an online apparel catalog and manages dynamic product listings via an integrated admin panel. The application demonstrates real-time state management between a decoupled frontend and backend architecture.

---

##  Features

- **Dynamic Product Catalog**: Displays clothing items grouped by category with dynamic pricing and media rendering.
- **Admin Control Panel**: Interface for adding new items (Title, Category, Price, Image URL) directly into the database.
- **RESTful API**: Flask backend serving structured JSON endpoints for data operations.
- **Persistent Storage**: Lightweight SQLite database maintaining inventory records.

---

## 🛠️ Tech Stack

### Frontend
- **React 18** (Vite template)
- **JavaScript (ES6+)**
- **CSS / Inline Styling**

### Backend
- **Python 3.11**
- **Flask** (REST API)
- **SQLite3**
- **Flask-CORS** (Cross-Origin Resource Sharing)
